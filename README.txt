大茅埔網站原型

快速開始：
1. 用 VS Code 開啟本資料夾，使用 Live Server 開啟 index.html；或在本資料夾執行 py -m http.server 8000，再到 http://localhost:8000。
2. 歷史脈絡、映月山房與大茅埔地圖三個分頁可切換。
3. 尚未匯入正式地形前，地圖顯示示意地形。
4. Blender 匯出 damaopu-terrain.glb，放進 models/ 資料夾後重新整理，網站會自動載入。
5. 模型裡的五個定位物件命名必須是：POI_TAIXING、POI_WUBEI、POI_DRAGON、POI_BEGONG、POI_CANAL。

請先閱讀「操作指南_網站與BlenderGIS.md」。
